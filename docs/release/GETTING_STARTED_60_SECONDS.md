# BatchClip 0.1.0: get started in 60 seconds

> Start this checklist after BatchClip's one-time 2–3 GB transcription setup has finished.

1. **Connect Gemini:** open **Settings → Connections**, add your Gemini API key, select **Test connection**, then **Save settings**. Never share this key.
2. **Choose the format:** in **Project lobby**, keep **Short clips (9:16)** selected.
3. **Add footage:** select **Import video** or drop a local video with clear spoken audio. MP4 or MOV is the safest beta input.
4. **Let BatchClip work:** keep the app open while it builds the local transcript, finds moments, frames speakers, and styles clips. Gemini analysis needs internet access.
5. **Review:** preview candidates and select **Approve** on the moments you want.
6. **Export:** select **Render Approved**, confirm the destination, and keep enough disk space free until every queued clip finishes.

Expected result: one or more captioned MP4 clips at **1080 × 1920 and 30 fps**. Processing and rendering usually take longer than 60 seconds; the 60 seconds covers the actions needed to start the workflow.

If a run fails, retry once, then use the [bug-report template](./BUG_REPORT_TEMPLATE.md) without attaching private media, transcripts, or API keys.
