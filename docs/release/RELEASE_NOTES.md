# BatchClip 0.1.0 beta release notes

BatchClip turns spoken long-form video into scored, reviewable clips with face-aware vertical framing and burned-in captions.

## What is included

- Local speech transcription and face detection.
- Gemini-assisted moment scoring, hooks, descriptions, and edit planning.
- Approve/reject review before export.
- Fixed 1080 × 1920, 30 fps short-form exports with captions and visual treatments.
- Early 1920 × 1080, 30 fps long-form editing path.
- Local project save, recovery, and encrypted API-key storage.
- Windows 10/11 x64 and Apple Silicon macOS 11+ builds.

## Beta status

Version 0.1.0 is an early test release. Builds are unsigned, first-run setup is large, rendering can be resource-intensive, and workflows may fail on unsupported media. Read the [beta warnings and known limitations](./BETA_WARNINGS_AND_LIMITATIONS.md) before installing.

**Distribution is currently blocked:** do not publish an installer or DMG until the repository [redistribution gate](../RELEASE_CHECKLIST.md) passes.
